## ✅ Week 1: Think Like a Machine (Concepts + Math)

### 🔍 Goals

* Understand what AI/ML is and how machines “learn”
* Learn the math that powers ML (intuitively)

### 🧠 Topics

* What is AI / ML / Deep Learning?
* Loss functions, gradients, optimization
* Linear algebra (vectors, dot product, matrix ops)
* Probability and statistics (distributions, conditional prob.)

### 🛠️ Code

* Implement Linear Regression from scratch using Python + Numpy
* Visualize data, gradients, and loss using Matplotlib

### 📘 Resources

* Book: *Grokking Machine Learning* (Ch. 1–4)

### 🧠 Topics

### 🛠️ Code
